## 2024-05-04 - Map and Calls Modal Accessibility
**Learning:** Icon-only control buttons within map and call modal overlays require explicit aria-labels, titles, and high-contrast focus rings for screen readers and keyboard navigation.
**Action:** Ensure all interactive modal controls, especially embedded icon-only actions, include semantic labels and explicit focus styling (e.g., focus-visible:ring-2 focus-visible:ring-[color]-500).
