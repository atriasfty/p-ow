## 2024-05-24 - Accessibility and keyboard navigation for icon-only buttons
**Learning:** The forms builder has multiple icon-only delete buttons (Trash2 icon) across sections, questions, and options that lack screen reader context and keyboard focus visibility.
**Action:** Ensure all icon-only utility buttons consistently implement aria-label, title tooltips, and focus-visible:ring-2 utilities to support both screen readers and keyboard navigation.
