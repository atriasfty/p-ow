## 2024-05-18 - Mod Panel Keyboard Accessibility
**Learning:** Found multiple icon-only interactive elements in modals and dropdown search results lacking explicit screen-reader contexts (`aria-label`/`title`) and proper keyboard focus visibility (`focus-visible`). Specifically, the map-modal zoom controls, modal close buttons, and custom autocomplete dropdown result items (`player-search.tsx`) required explicitly structured focus styles (`focus-visible:ring-2` vs `focus-visible:bg-zinc-700`) to ensure they met the project's accessibility standards without disrupting the visual design.
**Action:** Always verify that bespoke modals and custom combobox dropdowns (search results) include both structural accessibility markers and customized, highly-visible keyboard focus states, particularly when existing hover states don't translate naturally to keyboard tab interactions.
