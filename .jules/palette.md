## 2024-07-11 - Dialog Modal Accessibility
**Learning:** Custom dialog/modal containers must include semantic roles (dialog/alertdialog), aria-modal="true", and proper label associations. Icon-only close buttons and primary action buttons need explicit focus-visible styles with offset colors to appear clearly against dark backgrounds for keyboard navigability.
**Action:** Always add explicit ARIA roles, label associations, and focus-visible states with appropriate offsets to custom interactive elements within modals.
