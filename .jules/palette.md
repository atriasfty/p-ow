## 2024-06-16 - Dialog Accessibility Pattern
**Learning:** Custom dialog/modal containers must include semantic roles (`role="dialog"` or `role="alertdialog"`), `aria-modal="true"`, and proper label associations (`aria-labelledby`, `aria-describedby`). Icon-only modal close buttons and utility buttons must have a descriptive `aria-label`, a `title` tooltip, and explicit `focus-visible:outline-none focus-visible:ring-2` styling. This explicit focus styling must also be applied to all primary action buttons within custom dialogs (including `focus-visible:ring-offset-2`) to ensure clear keyboard navigability against dark backgrounds.
**Action:** Always verify custom modal containers provide complete ARIA structural context and that all interactive elements have visible focus states and descriptive labels.
