## 2024-06-24 - Custom Modal Accessibility
**Learning:** The custom modal components in this application (like `ConfirmModal`) lack native semantic roles, which makes them inaccessible to screen readers. Additionally, icon-only buttons need proper aria labels and explicit focus styling, and primary actions within dark modals need high contrast focus offset rings.
**Action:** Always ensure custom dialog containers include semantic roles (`role="dialog"` or `role="alertdialog"`), `aria-modal="true"`, and explicit label associations (`aria-labelledby`, `aria-describedby`). Icon-only close buttons need `title` tooltips and explicit focus styles. Primary buttons must use `focus-visible:ring-offset-2 focus-visible:ring-offset-zinc-900` for clear keyboard navigation. Decorative icons must use `aria-hidden="true"`.
