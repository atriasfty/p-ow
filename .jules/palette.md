## 2026-06-19 - Accessible Dialog Patterns
**Learning:** Custom dialog modals require semantic roles (dialog/alertdialog), aria-modal="true", proper aria-labelledby/describedby associations, and explicit dark-mode focus offsets (focus-visible:ring-offset-zinc-900) for close and action buttons to be usable by screen readers and keyboard navigation.
**Action:** Always include semantic roles, title/description associations, and explicit dark-themed focus offsets on interactive elements when building custom modals.
